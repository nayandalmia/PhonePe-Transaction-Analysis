# PhonePe Transaction Analysis

## Project Overview
Exploratory Data Analysis of PhonePe transaction data from 2018 to Q2 2021 using Python, Pandas, and NumPy.

## Objectives
- Analyze digital payment transaction trends.
- Identify state-wise transaction performance.
- Explore transaction categories and amounts.
- Analyze registered users and device brands.
- Understand quarterly and geographical patterns.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Project Outcomes
- Data cleaning and preprocessing.
- Exploratory Data Analysis.
- Grouping and aggregation using Pandas.
- Identifying trends and patterns in transaction data.
